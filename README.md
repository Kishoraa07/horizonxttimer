## 🎯 Features

- ⏱️ **36-Hour Authoritative Serverless Countdown Timer**: Synchronized millisecond-accurate timer across all connected devices and projector stages via Vercel serverless functions and MongoDB persistence.
- 🌌 **Cosmic Space Theme & Starfield**: Twinkling multi-spectral stars, shooting star meteors, and 3D WebGL cosmic background.
- 🛰️ **HorizonXT Voyager Core**: Interactive mission telemetry dispatch with sound chimes and 7 orbital milestone checkpoints.
- 📸 **Real-Time Live Event Photo Feed**: Instant live photo uploads powered by Cloudinary and MongoDB with built-in projector slideshow mode.
- 🎨 **HorizonXT Brand Color Palette**: Deep Cosmic Space Navy (`#030712`, `#0B1B3D`), Radiant Amber Gold (`#F59E0B`), and Electric Cyan (`#00C2CB`).
